# Impacto · instalar no Windows (time)

App para Windows 10 e 11 (64 bits) do sistema do Studio Impacto. Já vem conectado ao banco do Studio (Supabase): mesmos usuários, mesmos dados e atualização em tempo real.

### Instalar (recomendado)
1. Baixe **Impacto-Setup-0.1.0-windows-x64.exe** e dê dois cliques.
2. Como o instalador ainda não tem assinatura digital, o Windows mostra "O Windows protegeu o computador". Clique em **Mais informações** e depois em **Executar assim mesmo**.
3. Siga o instalador (não precisa de senha de administrador). Ele cria o atalho **Impacto** na Área de Trabalho e no Menu Iniciar e abre o app no fim.

### Versão portátil (sem instalar)
Se o computador não deixar instalar programas: baixe **Impacto-0.1.0-windows-x64-portatil.zip**, clique com o botão direito → **Extrair tudo**, abra a pasta **Impacto** e dê dois cliques em **Impacto.exe**.

### Entrar
Usuário **VITOR**, **MARCOS**, **PEDROPAULO** ou **YURI** · senha inicial `impacto2026` (troque em *User*).

### Observações
- Se o antivírus ou o firewall perguntar, permita o **Impacto**: ele roda um servidor interno só no próprio computador (127.0.0.1).
- Dados locais e configurações ficam em `%APPDATA%\Impacto`. Desinstalar pelo Painel de Controle mantém essa pasta.
- No Windows o menu fica escondido: aperte **Alt** para ver (Recarregar, Tela cheia, Pasta de dados).
- Também dá para usar pelo navegador: https://impacto-mu.vercel.app
